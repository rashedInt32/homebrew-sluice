# homebrew-sluice

The Homebrew tap for [sluice](https://github.com/rashedInt32/sluice): tmux-style sessions, windows and prefix keys on top of zmx, with raw PTY passthrough.

```sh
brew install rashedInt32/sluice/sluice
```

`Formula/sluice.rb` is written by sluice's release workflow on every version tag. Edit `.github/formula.sh` in the sluice repo instead.
